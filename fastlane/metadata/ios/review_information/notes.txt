Lexnur is an offline dictionary. On first launch the user chooses dictionaries, sees each download size before anything is downloaded, and downloads them once from our own server (dl.lexnur.com). After that the app works entirely offline; please try it in Airplane mode after the first download. The interface is bundled in the app, nothing is loaded from a website at run time, and there are no accounts, ads or tracking. It uses native sharing, haptics, Dynamic Type and the system back gesture. The third-party dictionary content is published under open licences that allow redistribution: Wiktionary (CC BY-SA 4.0 / GFDL), Open English WordNet (CC BY 4.0), Lane's Lexicon and Salmoné's dictionary from the Perseus Digital Library (CC BY-SA 3.0 US), Arabic WordNet 4 (CC BY 4.0), JMdict (EDRDG, CC BY-SA 4.0) and CC-CEDICT (CC BY-SA 4.0). Each source is credited on every entry and in Settings › Sources & licences.
